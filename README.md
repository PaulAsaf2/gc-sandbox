# gc-sandbox

Песочница для проверки локального города Gas City и дашборда
[gc-account](https://github.com/magnetto-agency/gc-account): сюда приходят
простые тестовые задачи («добавь файл», «поправь строку»), их выполняют агенты
локального города через тестовый GitHub App. Содержимое значения не имеет.

Ветки — как у настоящего проекта: `dev` — интеграционная (сюда агенты делают
pull request и сливают), `main` — «продакшен» (обновляется только из `dev`).
